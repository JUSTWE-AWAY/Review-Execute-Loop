# Final Deliverables

This directory contains user-approved final, publication-facing, release, or handover outputs. Keep exploratory, candidate, temporary, and rejected outputs elsewhere until the user approves promotion.

Use stable three-digit ordering and never renumber existing entries:

```text
deliverables/
├─ 001_<primary-deliverable>/
├─ 002_<supporting-deliverable>/
└─ 003_<additional-deliverable>/
```

Use only the subfolders that fit the artifact. Examples:

```text
001_manuscript/
├─ source/
├─ figures/
├─ tables/
└─ exports/

002_software_release/
├─ source/
├─ packages/
└─ docs/
```

Preserve editable sources and exported final forms when relevant. Do not put workflow prompts, logs, review packets, or unapproved candidates here. Do not overwrite or delete an approved deliverable merely to keep the numbering tidy; create a new version or numbered entry according to the project's approved scope.
