# Incoming Source Materials

Place user-supplied starting materials here: prior project records, old manuscript versions, data, models, code snapshots, notes, exports, reference files, or other inputs that existed before the current workflow run.

Everything under `incoming/` is immutable source material.

- Do not edit, rename, move, overwrite, quarantine, or delete files here.
- Do not execute untrusted scripts or binaries directly from this folder.
- Write inventories, hashes, extracted text, converted copies, cleaned data, trained models, analysis, and all derived outputs elsewhere.
- When adding later material, add a new file or a clearly named batch subfolder instead of replacing an earlier item.
- Record ambiguities, duplicates, unreadable files, and version relationships during Step 0.

Suggested optional batches:

```text
incoming/
├─ 001_initial_materials/
├─ 002_later_supplement/
└─ README.md
```

The numbered batch folders are optional. Existing user folder structure may be preserved exactly.
