# Generic Profile

Use for tasks that do not need a specialized research, software, or writing contract.

## Required Behavior

- Identify the source of truth for each important input.
- Keep changes inside the approved scope and write paths.
- Prefer new versions for completed deliverables instead of overwriting them.
- Validate the actual deliverable with the smallest relevant check.
- Distinguish observed facts, assumptions, and recommendations.
- Report external actions, unresolved dependencies, and unverified claims explicitly.

This profile adds no domain-specific Gate or mandatory artifact.
